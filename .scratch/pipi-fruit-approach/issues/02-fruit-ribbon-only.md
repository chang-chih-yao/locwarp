# 02 「瞬移+撈水果」按鈕只對彩帶花出現

Status: resolved
Blocked by: (none)
Type: feature
相關：`.scratch/pipi-flower-essence/spec.md`，2026-11-09 grilling 的 Q15

## 為什麼

2026-11-09 使用者說明了遊戲的機制，已經寫進 GLOSSARY 的**水果**：只有**彩帶花**在**彩帶期**內，有玩家在附近**種花**，才會結出水果。沒有彩帶的花，不管怎麼走都拿不到水果，只能**採精華**。

01 號票的 Q2 當時決定「在盛開期內的花」都出現這顆按鈕，那時還不知道水果只有彩帶期才會結。結果是對沒有彩帶的花按「瞬移+撈水果」，等於白走一趟。

Q15 決定把這件事另開成這張票，不併進拿過精華的功能，以免兩件事混在同一個 commit 裡。

## 做什麼

只有在打開 popup 的當下是彩帶花的花，才出現「瞬移+撈水果」按鈕。

- 盛開超過 60 分鐘、已經沒有彩帶的花不出現。
- 花苞、蘑菇、煙霧照舊不出現。

撈水果本身的流程都不變：起點正東 35 m、直線走、瞬移失敗就中止、群組模式、最近地點。
